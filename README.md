## Hi, I'm Alexandre 👋

Software engineer from Rio de Janeiro, building AI into real products.

I'm a co-founder and developer of **[Dreambook](https://apps.apple.com/br/app/dreambook-di%C3%A1rio-de-sonhos/id6478346247)**, an app for recording dreams and inducing lucid dreams, built with neuroscientists as advisors. I work across the Node.js/Prisma API and the React Native app, from subscriptions and authentication to the AI search behind similar-dream recommendations.

I study Systems Analysis and Development at UERJ, and I like the intersection of technology, psychology and AI.

## 🔭 What I'm working on

**TiêIA** — a local-first, AI-native video editor (a fork of OpenCut) · [repository](https://github.com/AlexandreLPA/tieia)

- Voice cloning with Chatterbox, running on a local GPU
- LLM routing through OpenRouter, with fallback between models
- An editing chat that sees the open project (frames, transcript, timeline) and proposes edits
- Whisper transcription, a "viral score" from speech, audio and image, and loudness normalization
- *In progress:* scene search over transcripts — BM25 and multilingual embeddings fused with RRF, measured with recall@5 and MRR

**Dreambook** — worked with the team on hybrid search over dreams (OpenAI dense embeddings + SPLADE sparse vectors in Qdrant, fused with RRF); I built the similar-dreams endpoint on top of it.
